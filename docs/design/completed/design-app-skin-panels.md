# AppSkin 顶栏、抽屉与复杂卡片槽位

## 配置与解析

全局契约新增 `AppSkin.topBar`、`drawer`、`cards` 三个分组，继续由统一解析器和
`AppSkinOverrides.withEdits` 合并。提供五个背景槽位：顶栏、抽屉背景、抽屉条目、
思维链卡片、工具卡片。旧配置缺少这些字段时继承宿主外观。

`AppSkinPanel` 包含可选背景材质、圆角、文字色、边框、横/纵留白和内容间距。
背景复用现有 `ChatBubble` 材质描述及有界图层渲染器，配置中的气泡几何归一为零，
宿主独立决定形状与留白。背景的隐藏/透明只影响绘制，不隐藏控件或操作。
边框宽度 null 表示继承宿主，0 明确关闭；其他可选字段 null 同样表示继承。

圆角最大 48 dp，边框最大 4 dp，留白与间距有界，颜色使用 `#RRGGBB`。
原生皮肤插件可直接提供这些类型；插件启停、缺失回退、命名空间和替换句柄沿用原注册机制。
内置「聊天外观方案」插件 1.4 增加包含胶囊顶栏、抽屉与卡片的完整柔和阅读示例。

## 宿主接入

- 聊天顶栏同时支持整条和浮动胶囊：皮肤可指定模式，也可跟随原 `topBarStyle` 设置。
  旧常规设置页同样显示解析后的模式，选择时建立有效的用户覆写，更新基于最新设置。
  标题、上下文读数、导航、更多菜单、任务入口继续由既有 TopBar 管理。
- 抽屉面板使用槽位背景/形状/留白；入口和会话行读取条目槽位，会话选中时保留选中提示。
  开关状态、手势、可访问性 pane、文件/会话切换和导航回调继续由原宿主管理。
- 思维链 CARD 档接入背景、形状、边框与间距。引用、极简及显式自定义档优先使用原有
  专属设置。步骤图标遮盖时间线的基色继续由原 cardColors 提供。
- 工具摘要、图片/拒绝说明所在内容块及详情面板接入稳定的装饰宿主。
  工具自己的渲染器负责内部控件和布局；内部显式不透明卡片仍可保留自己的填色。
  皮肤装饰不负责审批、跳过、表单状态或工具执行。

背景支持既有纯色、渐变、图案、噪声、图片纹理和内置 Shader 图层。自定义槽位材质的
玻璃为静态透光效果；顶栏选「跟随原背景」时，仍使用原实时模糊/玻璃开关和后台回退。
胶囊背景延续按滚动淡入的规则，图标按钮始终可用。

默认工具装饰不额外裁剪内容；配置圆角或材质时才建立相应裁剪。材质绘制保持在背景，
内容节点在热切换时常驻，避免重建输入会话或丢失折叠状态。

## 设置、预览与资源包

入口：「偏好设置 → 用户界面 → 应用皮肤 → 编辑全局样式」下方的五个槽位入口。
槽位 sheet 支持背景材质编辑、参数预览、恢复默认；只有保存到外层全局样式后才写入
应用配置，取消外层编辑不会应用槽位草稿。多字段编辑使用常驻的滚动 Column 和 IME padding。
颜色不完整时保留原输入并禁用保存，预览独立规范化。

主题包扫描聊天和全部槽位的图片引用，先校验所有资源再安装。为容纳最多 28 个图层
纹理引用，归档资源个数上限扩到 32，总资源上限仍为 32 MiB，清单 256 KiB；每个背景
仍最多四层。聊天 PNG 导出也提前持有槽位纹理，避免工具/思维链背景异步解码丢失。
完整备份沿用已有受保护的纹理目录。

## 验证

JVM 覆盖旧配置、模式继承、旧入口写入、参数边界、三组覆写、五槽位持久化/快照、
资源引用收集、归档数量上限，以及插件回退/恢复。真机覆盖原样像素、顶栏菜单、抽屉
嵌套点击、思维链折叠与样式优先级、工具输入焦点和审批/跳过、编辑器草稿、跨目录
纹理恢复及非法层数。另外回归已有外观/纹理/Shader、抽屉导航与缩放手势测试。

测试使用常规 debug 包，安装前备份数据库和设置，以 `adb install -r` 保留数据更新。

  13 项缩放抽屉手势/可访问性测试和 8 项抽屉导航测试。
- debug 主包与 instrumentation APK 构建成功；IME 审计 A/A' 命中均为 0，
  既有 B/C 告警保持 4/32，没有增加。
