# 本地皮肤资源包 v1

## 范围与入口

AppSkin 配置及其字体、应用内 Logo、默认聊天背景、五个面板槽位的纹理可一起打包。
设置入口：偏好设置 → 用户界面 → 应用皮肤 → 皮肤资源包。
图片编辑入口：编辑全局样式 → 皮肤图片资源。图片沿用规范化 PNG 存储，最长边 1024px。

这是全局 AppSkin 包：聊天专属外观仍使用原来的主题/材质分享入口，不自动覆盖聊天配置。
图标资源当前仅接入应用内 Logo，不替换系统桌面图标，也不覆盖全部 Lucide/HugeIcons。
背景是助手未指定图片或动态渐变时的聊天背景，尚非所有页面的通用壁纸。

## 文件与验证

ZIP 内只有 manifest.json 和 assets/<sha256>，不从 ZIP 条目生成任意文件路径。
清单含 formatVersion=1、稳定 ID、名称、递增版本号、AppSkin 与可选字体哈希。
字体只携带内容与显示名称；本机字体路径在导出时清空，安装后映射为 fonts/skin_pack_<hash>.ttf。
现有皮肤 PNG 共享 bubble-textures 中的哈希文件，Logo/背景也通过 AppSkin.resources 引用。

限制：32 个资源、解压后资源总量 48MiB、单资源 16MiB（图片另遵循现有 5MiB/1024px
校验）、清单 256KiB。拒绝重复 ZIP 条目、未知路径、越界读取、坏哈希、缺失或未引用资源、
无资源的 CUSTOM 字体、包内本机路径、不支持的格式版本及超过四层的面板材质。
图片解码与字体 Typeface 验证均在目录提交前完成。数据包不含脚本或动态 Shader 源码。

## 安装、升级与卸载

安装不自动切换外观；用户从已安装列表选择后进入同一 AppSkin 解析入口。
保留用户覆写，必要时可在主页面清除覆写以完整跟随皮肤。
同 ID 只接受更高版本，禁止同版本覆盖和降级，最多保留 32 个已安装方案。
资源先验证、再写入共享存储，最后用 AtomicFile 提交 skin-packages/index.json。
失败时旧目录与注册方案继续有效；提交前落地的孤立资源不进入注册目录。

已安装方案使用保留命名空间 package:<id>，插件不能注册这个 owner。
启动时后台加载目录；包升级发布到可观察 Registry，继续使用相同选择 ID。
应用完整备份包含平铺目录、字体和图片；恢复后重启加载。

卸载移除目录中的方案，原选择 ID 与用户覆写保留，解析器回退到默认；重新安装可恢复选择。
字体和图片可能仍被用户覆写、旧草稿或其他方案引用，因此不随卸载直接删除。
资源垃圾回收与总磁盘配额仍未提供。版本历史和回滚已由后续实现补齐，见
[试穿与回滚说明](design-skin-trials-and-rollback.md)。

## UI 与输入

安装/导出在 IO 上执行；元数据编辑位于常驻 Column + verticalScroll + imePadding。
图片与字体导入期间禁止外层保存，避免保存未完成的资源编辑。
通过系统文件选择器导入 ZIP、保存导出结果，不自动下载或上传。
卸载确认只显示只读说明，不包含表单。IME 审计 A=0、A'=0；B=4，C=34。
新增 C 是同文件同时含导出表单与只读卸载 AlertDialog 的启发式命中，表单实际在 sheet 内。
