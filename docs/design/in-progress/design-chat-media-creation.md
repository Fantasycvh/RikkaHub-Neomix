# 会话内媒体创作

2026-11-28。首期实现图片生成和参考图编辑，保留独立媒体创作页；视频工具留作后续能力扩展。

## 使用方式

- 普通聊天继续使用 `generate_image`。提交后立即返回持久创作记录，工具卡观察数据库显示进度和图片；聊天模型只获得状态、记录 ID 和素材 ID，不会自动收到生成图字节。
- 生成图下方的「作为参考图继续编辑」将图片复制到聊天附件区。输入修改要求后发送，工具通过 `reference_images` 选用素材。输入区现有文字保持不变；正在编辑历史消息时先完成当前编辑。
- 「打开创作记录」进入相同的媒体时间线。单张来源图属于当前时间线时，编辑作为原节点的新版本；来自其他聊天或已删除节点时建立新节点。
- 「停止等待」只停止该媒体任务的本地等待；远端请求可能已受理。停止聊天回复不取消媒体任务，离开页面也继续执行。
- 原独立生图页继续可用。聊天生成的终态图额外复制到原画廊；画廊和创作记录各自管理文件，删除创作记录不会破坏画廊副本。

新回合和完整会话读取会把异步任务的最终状态、素材 ID 和画廊路径补入工具结果快照，避免模型、导出结果一直看到最初的「生成中」。生成图仍然只以文本引用进入模型上下文。导出附件收集和路径改写识别 `generate_image` 的 JSON 图片引用；没有本地任务数据库的接收端可以使用图片快照查看或继续编辑。

局域网同步保持已有的 `upload` / `images` 白名单。将 `media_creation` 私有目录加入白名单的额外改动被自动审批拒绝，未实施；结果快照仅引用原画廊目录中的副本，不扩大私有目录外发范围。

## 记录与授权

`ChatMediaGeneration` 将聊天 ID 映射到独立媒体时间线 ID。来源聊天 ID 保存在草稿 JSON 的可选 `sourceConversationId` 字段中，旧草稿可直接读取。删除聊天不会级联删除独立创作时间线。

参考素材目录来自实际发送上下文的选中分支，仅取最近 32 条包含媒体的消息、最多 32 个可用素材。工具只接受目录中的 ID，不能用任意路径、URL 或其他分支 ID 读取文件。素材必须解析到当前应用私有目录内的已有文件；提交时复制到生成记录目录。聊天附件副本的来源元数据只有与当前上下文中的生成记录匹配时才能用于版本关联。

同一回合、模型、提示词、参数和素材组合映射到稳定记录 ID。重复工具调用返回原记录；本轮最多创建两次媒体请求，活动或提交结果不明的请求同样计入上限。创建请求成功或结果不明时不自动重提。

定时聊天保留已有授权执行路径，不开放参考图参数；预先批准的模型、参数范围和每轮一次约束继续生效。没有聊天归属的工具调用也保留原图片执行路径。

## 恢复与失败

- 有远端任务 ID：恢复查询；可查询接口即使创建响应已经是终态，也先保存任务 ID，保护后续下载窗口。
- 创建请求超时、网关错误或丢失响应：进入 `SUBMIT_UNKNOWN`，明确提示可能已经计费，重新提交由用户确认。
- 已收到成功响应但同步接口的下载被中断、且没有可查询任务 ID：同样保持待确认，不当作提交前的安全失败。
- 请求 ID 对账包括已落入 `SUBMIT_UNKNOWN` 的记录。查到后先恢复为活动状态，再续查；对账不提交新请求。
- 创建请求明确被接口拒绝，或素材准备阶段失败：普通失败。已知任务查询失败保留任务 ID，可以继续查询。

## 数据库与预览

Room 81→82 只增加两个非唯一索引，不改写业务列或清理历史重复数据：

- `media_creation_record(status)`：启动恢复按状态查找活动/待确认记录。
- `GenMediaEntity(path)`：聊天产物按固定路径幂等写入画廊。

创作节点和记录原有的 `session_id` / `node_id` 外键索引继续保留。删除创作时间线只读取记录 ID 来取消任务，随后执行数据库级联和 IO 线程文件清理；不再为取消任务解码全会话的提示词、参数和产物 JSON。编辑的节点归属通过主键单列查询确认。

共用全屏预览按 FIT 解码到最多 2048×2048，并关闭该请求的内存缓存读写。原文件、分享和保存仍使用原始文件。该限制约束静态图的预览解码和缓存，不等于整个应用的堆内存上限。

## 验证

新增 `ChatMediaToolTest` 覆盖重复提交去重、活动任务限额、错误引用、取消传播和待确认结果格式；扩展 `MediaInterruptionTest` 覆盖网关/超时与同步结果下载窗口。

`MediaGenerationAcceptanceTest` 的 `chatmedia` 场景通过回环 HTTP fixture 验证生成、同回合幂等、参考图编辑、版本、分支隔离、素材副本、HTTP 504、索引查询计划、5000 版本删除、8192×4096 原图预览解码，以及任务卡引用/打开动作。`seedchatmedia` / `recoverchatmedia` 覆盖进程被终止后的完成态和提交窗口恢复。

PJX110 的跨包 instrumentation 在测试代码运行前报 `Unable to find instrumentation info`。可使用 `scripts/verification/build_media_chat_host.py` 创建临时同包 debug 宿主：源码、清单和 Gradle init 均只写入 `build/media-chat-host/`；使用独立 `backupverification.debug` 应用 ID，常规与 release 构建不包含该宿主。
