# 长文 P2：显示文档与区块接口验收

基于 `6878aa9ba` 完成 P2 显示模型及 BetterText 最小扩展，未提交。实际聊天仍用完整 Markdown Column，不包含 P3 的列表懒加载、索引/跳转/选择适配，也不声称帧率收益。设计及坐标契约见 [实施说明](../completed/longtext-p2-display-document.md)。

## 实现与语义

- MessageDisplayDocument 保留完整原始 parts，复用现有分组策略，区分 header、正文/思维链/图表、footer，并记录原始 part 下标；文本解析会话按消息 UUID 与 part 下标隔离。
- 本地 `bettertext-markdown` 来源为 BetterText v0.1.5 / `46324cfb1da1bba043d5ba75ea09b2f1ada06f17`。九份上游主源文件中仅修改 Markdown.kt、MarkdownBlocks.kt、MarkdownStreamParser.kt，新增显示投影类型；静态语法转换、节点类型、CSS、行内处理与三个上游测试文件均保持原样，MIT 许可证一并保留。
- 显示单元连续覆盖 parser-normalized / streaming-completed renderSource，节点展平等于原文档 blocks。保留完整解析输入，不以显示范围代替原始消息坐标。HTML 语义分组不切断，列表、表格、围栏保持整体。
- 单调分配单元身份，追加时协调同起点尾块并复用稳定前缀描述，不使用内容 hash；非追加编辑更新 generation、分配新身份。稳定前缀不再创建全文临时映射和候选范围对象。
- 增加已解析单元的独立渲染入口，保留主题、组件、链接处理和全局标题位置。整条渲染继续使用原路径。
- 修复上游已记录的后置引用定义限制：尾部定义变化可影响前文，保守重新转换全文；含定义文档的非追加编辑同样全量失效，覆盖删除定义。

## 性能冒烟与限制

继续使用 P0 的隔离 Application、临时设置与内存数据库，无个人会话或模型请求；同一设备、默认外观、请求 60Hz、无补全，5 万字 mixed。每个场景各 3 轮，数值为逐轮指标的中位数，首绘帧排除。

| 独立 cohort | 场景 | 帧 P95 前 → 后 | deadline miss 前 → 后 |
|---|---|---:|---:|
| combined | scroll | 31.86 → 37.26 ms | 15.91% → 19.85% |
| combined | stream | 219.70 → 205.21 ms | 20.00% → 18.15% |
| static recheck | scroll | 31.38 → 27.12 ms | 20.31% → 20.61% |

combined 的静态 P95 升高 17%，因此增加独立的同参数静态前后配对复查；该升幅未复现。不同 cohort 保留独立来源，不合并挑选较好数字，也不据此宣称性能提升或完全排除小幅退化。P2 不以短测帧耗时作为收益验收，P3 接入实际懒加载后再做完整矩阵。

最终 combined 流式 ART 分配量中位数 105.52 → 106.77 MiB（约 +1.2%），GC 均为 1 次，稀疏采样 Java heap 峰值 206.71 → 211.84 MiB。它们包含整个测试负载，不是单次解析的精确分配/内存峰值。早期尚未去掉前缀临时对象的探索轮次分配量约 +8.2%，单独保留，未作为最终结果。
