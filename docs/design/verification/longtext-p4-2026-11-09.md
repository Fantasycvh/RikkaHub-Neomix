# 长文 P4：流式增量显示验收

基于 P3 `d5ac31b45` 完成。本文记录提交前的验收快照，后续提交与推送状态以 Git 为准。实现与回退范围见 [实施说明](../longtext-p4-streaming.md)。

## 实现

长消息使用串行后台解析会话，合并解析期间到达的中间快照；每个原始文本 part 保留自己的 parser。安全追加保留 epoch 和稳定前缀，后台解析时继续展示上一份投影；完整复制仍读取最新源码。生成结束用原会话执行 streaming=false 收尾，不再次创建完整解析器。

标准布局实色/隐藏气泡支持流式安全区块；其他布局及复杂气泡复用增量解析结果，继续完整渲染外观，没有宣称第三方布局或渐变/玻璃背景已分段。开关说明同步更新，关闭仍恢复原路径。

整条消息中部没有精确源码坐标，首次拆分会延迟到阅读开头/底部。引用、逻辑消息跳转和拖动解除跟随，明确到底部恢复跟随；生成结束继续完成最终布局。生成振动集中在稳定消息头，避免每个正文区块重复触发。

## 回归

最终 Debug / 测试 APK 构建通过。全应用 JVM 3250 项、Markdown 44 项，无失败；应用原有两项跳过。新增会话测试检查稳定前缀实例、epoch、未闭合围栏收尾、分支/非追加编辑失效；索引测试增加正在阅读整条消息时的延迟拆分。

真机 PJX110 / Android 15 共 21 项：原有选择、完整复制、引用/分支、阅读恢复、外观、长文编辑和 Markdown 投影，加上生成中追加至结束保留区块/像素偏移、首次拆分延迟、收尾后仍贴底。原有 P3 “本次生成一直保持完整宿主”的预期被流式区块行为替换，而不是删除这一场景。

专项测试先后暴露了贴底覆盖明确阅读跳转，以及跳转动画起点仍在底部时误恢复跟随的问题。修正后，程序化跳转解除跟随，只有实际手指拖到底部或明确到底部命令才恢复；已贴底不重复请求布局。失败日志保留在工作区用于追溯。

IME 审计 A=0、A'=0，原有 B=4、C=32 告警；差异空白检查通过。剪贴板测试沿用 P3 的 LocalClipboard 捕获实际写入载荷，未修改 ROM 剪贴板权限。测试隔离使用内存数据库、临时设置和离线样本，未清空个人数据、未调用模型接口。
