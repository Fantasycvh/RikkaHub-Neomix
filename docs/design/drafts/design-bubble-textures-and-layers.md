# 图片纹理与气泡图层

本地实现说明。范围为图片导入、最多四层叠加、材质/主题资源包；不包含自定义 Shader。

## 数据与兼容

`ChatBubble.stack == null` 保留旧渲染分支。编辑器打开时投影成等价 `BubbleStack`，
保存前只修改本地草稿；取消不写设置。显式空栈表示不绘制底色。
新栈进入 `ChatAppearanceDetails.userStack/assistantStack`，沿既有统一配置入口持久化，
插件也可直接提供相同类型的方案。

栈由可选的玻璃背景和最多四个绘制图层组成。每层具有持久化稳定 ID、类型、启停、
不透明度与混合方式；顺序由列表决定，后面的层覆盖在前面层上。支持纯色、渐变、
内置图案、颗粒噪声、图片纹理；混合支持正常、正片叠底、滤色、叠加。
首个实际绘制的图层使用正常混合。整体透明度对合成结果统一应用。

旧配置投影是确定性的，不在重组时生成随机 ID；规范化限制资源数量与数值，修复重复 ID。
编辑态不会经过规范化回写，非法/未完成的色值只影响保存按钮，不影响 IME 编辑缓冲。

## 图片资源

支持 PNG、JPEG、WebP 静态图片，导入上限 16 MiB，最长边规范到不超过 1024 px。
应用 EXIF 翻转/旋转并保存透明 PNG。配置仅引用 PNG 内容的 SHA-256，不保存设备路径。
资源位于 `files/bubble-textures/<hash>.png`；同图去重、原子落盘，缺失资源跳过该层。
该目录纳入统一备份/恢复目录表，不会被普通聊天附件清理删除。

纹理支持平铺、镜像平铺、铺满，以及宽度与水平/垂直偏移。
解码在 IO 上完成；并发请求串行复用缓存，缓存以文件路径分区、按字节限制为 16 MiB。
缓存淘汰不回收仍在绘制的 Bitmap。PNG 导出提前加载并持有所有引用纹理，避免异步图片
尚未完成加载就开始捕获。

## 长消息与合成

保留现有 Markdown 分段与懒加载。消息片段共享绘制坐标，平铺/噪声不在每段重新起图；
参考片段离开视口时把坐标基准交给仍挂载的片段。坐标只在绘制阶段读取，不要求测量
屏幕外的整篇 Markdown；注册表限制为 128 个消息组，历史坐标限制为每组 512 条。

铺满图片及纵向渐变使用共同的已测范围，该范围随长消息的后续测量扩大；不承诺在尚未
测量消息尾部时提前获得整篇最终高度。平铺模式保持相位连续。

不透明度小于 1 或使用混合时，仅为 Canvas 可见裁剪范围建立离屏组，避免分配与整条
超长消息同高的缓冲。正文、工具操作、选择及点击继续由共享气泡宿主管理。

## 设置与分享

入口：偏好设置 → 用户界面 → 聊天外观 → 用户/助手气泡材质 → 编辑。
编辑器是 `ModalBottomSheet + Column + verticalScroll + imePadding`；图层节点以稳定 ID
作为 key，支持增删、排序、启停、混合、参数编辑与即时预览。

材质包 `.neomix.zip` 为 ZIP：`manifest.json` 是版本化的气泡描述，
`textures/<hash>.png` 为引用资源。主题含纹理时也导出同结构主题包，无纹理主题保留
原剪贴板 JSON 导出。主题页提供文件导入入口，仍由用户确认是否应用外观。

共享归档传输限制为最多 32 个资源（应用皮肤槽位接入后扩容）、32 MiB 资源总量、256 KiB 清单；拒绝未知路径、
重复条目、哈希不符和缺失引用，先验证全部图片再安装。不执行归档内任何代码。
本机完整备份与便携材质/主题包都能携带图片，不依赖跨设备悬空路径。

## 验证

JVM 测试覆盖旧材质投影、顺序和混合参数持久化/快照、数量及数值归一、归档校验，
以及滚动/参考片段释放后的纹理相位。既有备份覆盖测试验证新目录的打包和恢复分派。
常规 debug instrumentation 使用独立的缓存目录保存测试图片，不修改用户配置，
覆盖图片去重/缩小/透明、材质与主题资源包、混合像素、整体透明度、三种纹理铺放方式、
分段连续性、旧材质像素等价，以及编辑器只在保存时提交草稿。

测试使用 `adb install -r` 更新常规 debug 包，没有调用 clear-data 或卸载主包。
