## 二、发布流程（固定）

1. bump versionCode（`app/build.gradle.kts`，**续增不重置**，253 已用）；
2. `bash scripts/build.sh release`（自动改名 arm64 产物到 `app/release/`；勿用 `-Pandroid.injected.build.abi`，OOM 用脚本内置 `--max-workers=2`）；
3. aapt 验证 versionCode/架构；
4. debug 先装机实测 → `gh release create vX.Y.Z --draft -R androidrik/rikka2-my_feature_open`（双语 ≤10 条日志，先请用户确认）→ 用户检查后 `gh release edit --draft=false --latest`。
5. **tag 一律带 `v` 前缀**（与 `.claude/commands/publish-release.md` 中"不带 v"的记载相反，以实际为准；旧 release tag 多数**不带** v，删除时须用实际 tag 名）。
6. README 下载标注随发布更新。
