### 🌳 会话树形分支

- **非破坏分支**：编辑/重新生成保留旧时间线并开新子树，撤销机制退役（数据零丢失）
- **树视图**：会话内树面板、树内分叉、时间线切换、跨分支引用跳转（quoteJump）
- **散列寻址**：节点按 id 与路径寻址（P0 基座），流式检查点在同一事务推进激活叶子，强杀后不再丢半截回复
- **Web / 导入导出对齐**：激活路径 flatten、全分支导出、导入树字段 remap
- 长对话树面板只在真分叉处增加缩进并封顶，避免内容被挤出屏幕

### 🧠 记忆增强

- **助手级双记忆模式**：可按助手选择记忆策略，补齐本地化
- **文件记忆分类与整理**：支持文件记忆的分类管理与整理流程

### 🔌 DeepSeek Tool API 适配

- 内置 web tools 收发、互斥守卫、OCR 可选后端、TTS/ASR provider 与设置降级路径
- P2：工具计费落账与刊例价估算、`usage_record` 配料与工具计费三列、安全审核开关
- 官方契约摘编、仓库审计与真实 Key 探测记录在档

### 📊 统计与用量

- 工具计费统计改按**计费单位**分项展示，补齐 Chat Completions / Responses / Claude 兼容三类协议的流式与非流式解析
- 用量筛选：自定义区间 + 提供商/模型 chips（DAO 过滤与状态机两层）

### ⚡ 压缩与上下文

- **压缩后在新会话继续**（可选项）：把摘要与压缩窗口内原文复制到新会话并打开，旧会话保留为归档；新会话节点数大幅下降
- **压缩阶段进度**：准备 / 分块 i/n / 覆盖率校验 / 整篇重摘 / 兜底，对话框显示进度条，不再长时间只转圈
- **自动压缩提前化**：开启自动压缩后，每轮正常结束即按阈值后台压缩，下一次发送不再把压缩耗时算进等待；后台与手动/中途压缩按会话串行化
- 会话树、根检查点折叠行的「已压缩 N 条」显示修正

### 🎨 界面与输入

- 第三轮 UI：IA 值 chip 与高级折叠、motion 令牌收编、气泡限宽与尾角接线、内置皮肤与聊天外观联动
- 页面级穿底顶栏 + 抽屉玻璃出聊天域；Expressive 排版令牌、material3 rc01
- 浮动输入 pill、低频图标组输入态淡入淡出、Agentic 工具卡片阶段步进、流式正文块淡入
- 模型/提供商卡片 75%–150% 连续缩放；模型选择列表长名称支持两行折行

### 🛠 修复

- **Gemini**：容忍独立 `thoughtSignature` part，不再在流末 `unknown message part type` 崩溃；Gemini 签名推理块禁止编辑，避免签名失效
- **IME**：设置类文本域写穿回灌全量迁移（本地权威 + 去抖单向写），修复中文输入丢字/抖动
- 重新生成/续写后自动滚动跟随失效；FAB 被测量拉成横贯全屏卡片；会话树长对话缩进溢出
- 工作区 `.md` 打开默认渲染预览，可切换源码；DeepSeek OCR 六字段漏接设置落盘
- 快捷消息、TTS、多图裁剪等细节修复
- `message_node` 索引改为 `(conversation_id, node_index)` 复合索引（长会话分页读平方级问题）
- 压缩阶梯阶段回调与单测、树模型/窗口/压缩回归测试；静态审计与单元测试门禁
