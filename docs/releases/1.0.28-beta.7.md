### 🧪 插件系统（实验性 / experimental）

> **本版起插件为实验性功能**：插件 API（`plugin-api`）与 manifest 字段仍可能变动，
> **不保证向后兼容**；请勿把它当作稳定扩展点。JSON 规则插件与 JS 插件均可在插件页停用/卸载。

- **插件中心**：设置 → 扩展管理 → 插件，支持启用 / 停用 / 详情 / 卸载；启用状态经 DataStore 持久化，重启后恢复
- **两种可安装形态**
  - **JSON 规则插件**：宿主规则引擎解释执行，按条件（字段 / 比较 / 逻辑组合）做输入或输出侧改写；可直接粘贴 JSON 或从 HTTPS 链接导入
  - **JS 单文件插件**：QuickJS 沙箱，单文件自描述清单（`target`: input / output / both），无模块系统、无构建步骤；单次调用超时（300–5000ms，默认 1500ms）、日志截断、跑完即销毁
- **能力声明 + 逐项授权**：`NETWORK` / `HISTORY_READ` / `CONVERSATION_MUTATE` / `TOOL_REGISTER` / `PROMPT_TRANSFORM` / `OUTPUT_TRANSFORM` / `STORAGE`；
  安装时逐项确认，运行期在调用点再次校验（不是只靠安装期一次），装后可在详情页撤销已授权能力
- **出站网络受控**：JS 插件只能经宿主 `rikka.http` 发请求——清单 `networkHosts` 作正向白名单（支持 `*.example.com`，默认拒绝），
  内网 / 环回 / 链路本地 / 保留地址硬拦截，DNS 解析结果复核（基础 rebinding 防护）
- **扩展点**：原生插件可注册自己的工具调用 UI 渲染器（宿主统一挂载/注销，禁用后不残留）；输入/输出侧均可参与转换管线
- **样例**：`docs/samples/plugin-rules/`、`docs/samples/js-plugins/`（可粘贴导入，含 GitHub Zen、去 emoji、广告行剔除等）
- 设计取舍与真机验证记录见 [`docs/PLUGIN_SYSTEM_DESIGN_DRAFT.md`](https://github.com/Fantasycvh/RikkaHub-Neomix/blob/master/docs/PLUGIN_SYSTEM_DESIGN_DRAFT.md)；
  插件体系思路借鉴 [BiliPai](https://github.com/jay3-yy/BiliPai)，未复制其代码

### ⚡ 提示词与 token 计数性能

- **预分词改为手写扫描器**（替代 `java.util.regex`）：设备实测同一段 11.5 万字符，正则扫描 2572ms（debug）/ 2386ms（release），
  手写扫描 **26ms**；桌面 JVM 同一段只要 2–3ms ⇒ 慢在设备的 regex 实现，与模式复杂度、构建类型都无关
- 收益落在所有依赖 token 计数的地方：请求内容预览、上下文占用条、自动压缩触发、记忆注入预算
- 易变区段切分改为单次流式遍历（不再物化两万多个 `MatchResult`），切分 4392ms → 3551ms
- 切分总数写回持久缓存 + 整段命中快路径：129KB 构造会话冷启组装 **3787ms → 197ms**，
  同进程二次预览 **1ms**，重启后再次打开 56ms
- 正确性由「与正则逐片段对拍」保证：30+ 边界向量 + **6 万条随机语料**（CJK/韩文/假名/阿拉伯数字/罗马数字/emoji ZWJ/组合符/各类空白）
