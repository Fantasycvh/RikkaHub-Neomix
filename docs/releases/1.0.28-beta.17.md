### 🧱 富文本渲染迁移 BetterText（本版主功能）

Markdown / 公式 / 代码高亮换到 BetterText（`text` + `markdown` + `latex` + `highlight`，v0.1.3，JitPack），删除自研 `Markdown.kt` / `MarkdownNew.kt` / `SimpleHtmlBlock.kt` / `MarkdownStreaming.kt` / `LatexText.kt` / `MathBlock.kt` / `CodeColor.kt` 与 `:highlight` 模块：

- **公式**：行内公式行高/基线、长公式折行、表格内公式、块公式统一由 BetterText/KaTeX 渲染；TikZ 图块仍走 `TikzJax`（保留）。
- **消息渲染**：citation 角标、引用块、`details`、表格卡片、代码高亮与代码块选择；消息文字统一迁到 `BetterSelectionContainer`（思考流式期间也可选）。
- **导出**：HTML 导出所需的 Markdown/公式转换抽到 `MarkdownHtml.kt` 保留，导出与屏显同源。
- **TikZ 兼容修复**：模型输出的 `$$…$$` 块内在 `\node`/`\draw` 之间带空行时，GFM block math 会提前结束——新增 `DisplayMathNormalizer.normalizeDisplayMath()`（跳过代码围栏内空行），聊天渲染与导出共用；另在 `MATH_HINT` 中禁止「反斜杠后直接跟中文」这类控制符号写法（`PromptAssemblyTest` 加断言防回退）。

### 🤖 任务控制面 / 任务中心（P0–P4b）

- **任务中心**：把「子代理运行 / 后台命令 / 定时运行」三段合成一个只读聚合视图（统一 `TaskCard`、筛选、取消、批准、详情跳转），并按「需要人 → 进行中 → 最近」分段；待批任务给「待批」入口。
- **后台子代理**：独立持久化投递账本（DB v58）、完成/待批通知、系统通知与「用户消息载体」两种投递方式可切换；应用重启后按账本补投，不静默丢。
- **后台命令控制面**：独立 `ExecutionScope` 级联取消、孤儿进程扫描（应用重启后 reparent 到 init 的旧任务可被发现）、工作区详情里的后台任务卡带输出与剩余时长。
- **定时任务**：运行账本进任务中心（P4a）；可选 headless `agent_run` 执行路径（默认关，开启后不再注入目标会话，结果经通知投递）。
- **入口收敛（本版收尾）**：`taskCenterEnabled = true` 时扩展页只留「任务中心」（旧 Agent 运行列表隐藏）；「新建运行」FAB 迁入任务中心；定时任务管理页从设置页迁入任务中心顶栏；后台命令卡点击进工作区详情（含输出）。关闭开关则完全回退到旧入口。
- 回滚开关矩阵：任务中心 / 通知命名空间 / 动态并发闸 / run 取消级联收 shell 任务，均可在设置里单独回退。

### ⚠️ 升级与降级

1. **升级前先备份**：设置 → 备份 → 立即备份（旧备份仍可恢复，恢复时走迁移把 DB 升到 58）。
2. **不建议降级**：DB 升到 58 后旧版本无法直接打开（无降级迁移）；`data_version = 6` 也会被旧版本忽略。
3. **必须降级时**：卸载后重装旧版本，再从升级前的备份恢复；直接覆盖安装旧 APK 会读到已升级数据。
4. 降级后再升回本版：DB 重新迁移到 58、DataStore 迁移幂等（内置默认助手合并不会重复执行）。
