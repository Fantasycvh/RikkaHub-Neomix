# RikkaHub Neomix — 1.0.28-beta.25 (329)

### 更新内容

- 文件↔会话关联：文件管理显示每个文件所属的会话并支持一键跳转；新增消息级关联表，附件增删实时同步，存量数据启动时自动回填。
- 会话列表多选批量迁移到指定助手，文件夹跟随语义：目标助手有同名文件夹则归并、没有则克隆，原文件夹不动；单会话「移至助手」入口同步为同一语义（不再清空文件夹归属）。
- 助手详情页分组并折叠进阶项，常用配置优先展示。
- 皮肤↔聊天外观联动升级为「绑定 + 可解绑覆写」模型。
- 压缩：执行前支持范围预览确认；压缩记录展示计数（`#N · 本次 M 条`）。
- 导出显示配置支持消息时间戳（上游 #2368）。
- 会话列表支持定位当前聊天，删除后视口稳定不跳。
- 生图支持提示词优化；支持导入生图模型。
- 页面导航本地统计（debug 侧统计入口）。
- 新增商汤日日新供应商图标，扩展 NVIDIA 匹配规则。

### 问题修复

- Release 包保留 Screen 类族 keepnames，修复导航统计路由名被 R8 混淆。
- 历史对话工具按助手隔离，不再跨助手串历史。
- 定时任务授权返回后刷新权限提示状态，避免提示残留。

### Updates

- File↔conversation linking: file management shows which conversations each file belongs to with one-tap jump; a message-level ref table keeps links in sync and existing data is backfilled on startup.
- Batch-migrate conversations to another assistant from multi-select, with folder-follow semantics: merge into a same-name folder under the target assistant or clone one; the single-conversation "move to assistant" entry adopts the same semantics (no longer clears folder).
- Assistant detail page groups and collapses advanced settings.
- Skin ↔ chat appearance linking upgraded to bind-with-optional-override.
- Compression: scope preview confirmation before running; record counter display.
- Export display config supports message timestamps (upstream #2368).
- Conversation list can locate the current chat; viewport stays stable after deletion.
- Image generation supports prompt optimization and importing image models.
- Local navigation statistics (debug-facing).
- Added SenseNova provider icon; extended NVIDIA matching rules.

### Fixes

- Screen classes keep their names in release builds; navigation statistics route names are no longer obfuscated by R8.
- The conversation-history tool is now per-assistant isolated.
- Scheduled task permission prompt state refreshes after returning from authorization.

### 升级 / Upgrade

从 beta.24 覆盖升级会将数据库从 78 迁移到 80。升级前请在「设置 → 备份」保存副本。回到旧版本需要重装旧版并恢复升级前的备份。

Upgrading from beta.24 migrates the database from version 78 to 80. Back up in Settings before upgrading. To return to an older version, reinstall it and restore the pre-upgrade backup.
