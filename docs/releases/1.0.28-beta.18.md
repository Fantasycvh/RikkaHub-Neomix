## RikkaHub Neomix — 1.0.28-beta.18 (321)

`versionCode` 320 → **321**，Room 数据库版本 58 → **60**（AutoMigration ×2：会话级/按消息导出显示覆盖）；与 beta.1…beta.17 同签名密钥，可直接覆盖安装升级。

### ✨ 备份体系 P2 全套

- **数据库逻辑对象增量备份**：按对象（非整库）增量打包，含跨 schema 恢复、FTS 索引重建进度、对象 GC 与保留策略
- **回收与拆包**：备份 pack 内单条回收（拆包）、回收与拆包全程进度提示；多设备 GC 安全协议
- **快照导出完整 ZIP**；增量备份全链路速度优化（SAF 逐对象往返治理、单次回收内并行拆包、预估/提交提速）
- **前台服务**：备份任务离页/后台继续
- 备份页信息架构重构：二级列表 + 三级详情页

### ✨ 导出

- **导出显示覆盖**：会话级与按消息粒度（支持多选批量设置）控制导出内容
- 导出标签占位符扩展、内置命名方案、支持隐藏提供商/模型与自定义模板

### ✨ 插件运行时（**实验性**）

- **转换链装配注册化**（P1）：转换器贡献具备稳定 id 与宿主阶段；插件生命周期贡献绑定注册实例代次；预览只执行宿主审核过的只读贡献（预热不运行任何插件）
- **工具统一**（P2）：来源标识类型化（信封/诊断/审批表单一真源）；插件工具与内置/MCP 跨段重名 → **报错拒绝装配**（模型可见名不变）；「来源 → 审批基线」表入档并接诊断；诊断一行回答三问（来源/审批/超时）
- **开发者修订通道**：改插件不再需要重装 APK——应用内整页编辑器、提交预检（manifest/语法/顶层求值/工具闸门/画像五闸）、失败自动兜底 last-good、版本历史与一键回退、ADB inbox 快速通道（push 即生效）、从设备文件导入（SAF）；生效时机为代次切换（运行中回合不偷换实现）
