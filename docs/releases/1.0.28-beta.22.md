## RikkaHub Neomix — 1.0.28-beta.22 (325)

### 更新内容

- 打开长会话、浏览会话树和切换分支更流畅。历史空回答仍可切换候选，新生成的空回答会提示出错。
- 文件记忆新增空闲整理范围、参考历史聊天记录和时间提醒设置。可将选定的文件固化到当前会话或助手的全部会话。
- 支持导入 DeepSeek 官方导出包和 Chatbox v2 ZIP 备份。
- 新增工程感和 iOS 风格皮肤及分组容器样式。提供商设置中的长模型名称可完整换行显示。
- 导出文件过期清理后，文件管理列表会同步移除对应记录。

### Updates

- Open long chats, browse conversation trees, and switch branches more smoothly. You can still switch alternatives for older empty replies, and new empty replies show an error.
- File memory now lets you choose which past turns to organize, reference past chats, set time reminders, and pin selected files in the current chat or across an assistant’s chats.
- Import official DeepSeek exports and Chatbox v2 ZIP backups.
- Try new engineering-inspired and iOS-style skins and group layouts. Long model names now wrap in provider settings.
- The file list now removes expired exports after cleanup.

### 升级 / Upgrade

从 beta.21 覆盖升级会将数据库从 71 迁移到 73。升级前请在「设置 → 备份」保存副本。回到旧版本需要重装旧版并恢复升级前的备份。

Upgrading from beta.21 migrates the database from version 71 to 73. Back up in Settings before upgrading. To return to an older version, reinstall it and restore the pre-upgrade backup.
