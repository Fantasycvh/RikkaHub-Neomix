### ✨ 本次更新 / What's New

**缓存管理（新）**

- 设置 → 连接与数据 → 缓存管理：统计并清理 7 类可再生缓存（图片缓存 / 临时文件 / 网页内容缓存 /
  缩略图 / 公式渲染缓存 / 日志 / 备份临时文件）
- 白名单驱动：只删目录内容、保留目录本身；聊天记录、附件、头像、生成产物、数据库与工作区文件
  不进入清理范围
- 备份临时文件与日志可展开查看逐文件大小
- 清理结果带分类名与释放量；部分文件删除失败时逐项列出
- 备份/恢复进行中禁用清理并给出提示，避免误删正在写入的归档
- 设置页「聊天记录存储」计数在返回时重新计算

**应用名称与图标自定义**

- 应用内显示名：用于「关于」页标题与最近任务标题，留空恢复默认
- 桌面「名称 + 图标」预置切换（5 套：Neomix 默认 / RikkaHub / Chat / Notes / Assistant）
- 桌面快捷方式：固定名称 + 可选相册图片（居中裁剪 432²）

**修复**

- 余额求值与显示固定 `Locale.ROOT`：小数点与千分位不再随系统语言变化
- `search_web` 描述按服务真实能力拼装：不再向模型声明签名里不存在的过滤能力

**其他**

- 移除 New API / Agent Router 两条内置提供商（如需可自行添加）
- 设置全局搜索新增「缓存管理」条目；「存储管理 / 存储空间」保留为兼容关键词
