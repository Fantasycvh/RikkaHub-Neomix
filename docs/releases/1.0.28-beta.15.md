- **外观快照导入导出**：主题 + 外观设置一体化快照（兼容旧版裸主题 JSON）；「同时应用外观」勾选默认关闭

**轻量个性化（聊天页三件 + 自定义导入）**：

### 🛠 稳定性与修复

- **IME 输入陷阱根治（本版重点修复）**：角色覆写槽位编辑框内联在 LazyColumn item 中，键盘弹起收缩视口 → 焦点字段被裁出 → item 销毁重建 → 逐字符回退 / 光标漂移 / 字符重复。同族 bug 本仓已发生四次，本版：
  - 槽位编辑改为 ModalBottomSheet（常驻容器子项不被销毁），输入框本地态 + 仅合法值提交，回调改读-改-写防快速连打丢更新
  - 自动压缩对话框补滚动 + imePadding（输入法遮挡同族现症）
  - 防回归三件套：AGENTS.md「TextField Host Rules」三条禁令 + `scripts/audit_ime_trap.py` 审计脚本（现症阻断 + 隐患告警）入库
- **设置入口修复**：M3 `ListItem` 的 supportingContent 槽位只渲染第一个直接子节点，条件行（选中态内容 / 编辑入口）被静默吞掉——统一 `Column` 包裹修复；头像框 / 思维链自定义入口直达（点 chip 即弹编辑器，不再需要二级按钮）
- **选图裁剪补齐**：快捷方式图标选图即弹 1:1 交互裁剪
- **JSON 导入白做修复**（重切追加）：自定义参数框 / 思维链自定义样式的「导入 JSON」确认后原会直接关闭编辑 sheet——导入解析写的是编辑器本地态，随关闭丢弃，导入等于无效。改为导入后保持 sheet 打开、表单回填导入值，点「保存」才落库；真机 导入 → 回填 → 保存 → 持久化 全链路复测通过
