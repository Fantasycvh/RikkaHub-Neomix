## RikkaHub Neomix — 1.0.28-beta.23 (327)

### 更新内容

- 聊天输入框输入 `/` 即可挑选技能，选中后按技能设定继续对话。
- 备份与恢复更细：可按设置类别与文件分组选择备份范围；恢复支持「覆盖」与「合并」两种方式，还能只恢复对话对象；新增「从原版 RikkaHub 导入」独立入口；崩溃页与启动失败页也能直接导出备份。
- 备份更可移植：设备本地状态不随备份迁移；启动次数拆分为「本机」与「跨设备累计」两个口径，换机恢复时跨设备累计取较大值合并。
- 接入 Vertex Gemini Interactions API 与 Deep Research，支持增量续接；文件记忆新增修改历史与回收站，可回溯并恢复历史版本。
- 工作区支持挂载共享存储目录；安全模式下可一键清理占用过大的设置项；气泡模式按段落拆分渲染，长段落不再整块重排。
- 统计页把启动次数拆成「跨设备累计」与「本机」两张卡，并标注各自的数据来源。

### 问题修复

- 修复玻璃顶栏可选插槽为空时的崩溃。
- 修复文件名含 `#` 时在 Android 9/10 上识别 MIME 类型崩溃的问题。
- 限制 DeepSeek 内置网页工具只在适用端点启用，避免请求被发到不支持该能力的服务商。
- 保留 Vertex/Gemini 搜索回复的正文、续轮签名与工具块，多轮搜索不再丢内容。

### Updates

- Type `/` in the composer to pick a skill and continue with its setup.
- Backup and restore are more granular: choose setting categories and file groups, restore with overwrite or merge, or restore only conversations; there is a separate entry for importing an original RikkaHub backup, and crash/startup-failure screens can export a backup directly.
- Backups are more portable: device-local state no longer travels with the backup; launch counts are split into on-device and cross-device totals, merged by taking the larger value when restoring.
- Vertex Gemini Interactions API and Deep Research are supported, including incremental continuation. File memory gains version history and a recycle bin for restoring earlier revisions.
- Workspaces can mount shared storage directories; safe mode can clear oversized settings; chat bubbles render by paragraphs.
- The stats page shows launch counts as separate cross-device and on-device cards with their data sources.

### Fixes

- Fixed a crash when the glass top bar's optional slot was empty.
- Fixed a crash on Android 9/10 when guessing the MIME type of a file whose name contains `#`.
- DeepSeek's built-in web tools are now limited to supported endpoints.
- Vertex/Gemini search replies keep their text, signatures, and tool blocks across turns.

### 升级 / Upgrade

从 beta.22 覆盖升级会将数据库从 73 迁移到 75。升级前请在「设置 → 备份」保存副本。回到旧版本需要重装旧版并恢复升级前的备份。

Upgrading from beta.22 migrates the database from version 73 to 75. Back up in Settings before upgrading. To return to an older version, reinstall it and restore the pre-upgrade backup.
