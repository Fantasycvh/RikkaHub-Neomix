### ✨ 本次更新 / What's New

**SSH 远程工作区（新）**

- 工作区新增 SSH 类型：连接远程主机后，AI 的文件读写 / Shell / 终端工具直接作用于远程目录
- 编辑页新增 SSH 连接配置；详情页显示连接状态卡；按主机能力自动裁剪（无 rootfs / 终端 / 写文件 / 后台任务时隐藏对应入口）
- 凭据（密码 / 私钥口令）经 Android Keystore AES-GCM 加密落库；主机密钥校验防中间人
- 远程 cwd 与 `@` 补全、远程提示词注入

**交互式终端（新）**

- 新增终端模块（基于 termux terminal-emulator）：本地终端迁移至同一实现，SSH 主机可开交互式终端会话
- 本地终端保留 PRoot 挂载与兼容模式

**上下文净化 P0（观察期，默认不改任何行为）**

- 新增「思维退化残留」的发送侧 dry-run：真实请求组装时判定历史中的字面重复残留（推理周期 / 块级重复 / part 级重复 / 工具空转），**只记录、不修改发送内容**
- 拼装预览页新增「净化 dry-run」卡：最近一次请求的窗口条数、命中决策、可省字符
- Logcat 标签 `purge.dryrun`：命中明细与「窗口 hash 相同但决策翻转」告警
- 观察期数据将决定 P1（真正执行净化）是否解禁，见 `docs/design/design-context-purification.md`

**改进**

- 压缩对话框「保留最近消息数」由步进器改为数字直接填写（范围 0–999，负数 / 非法输入不生效）
