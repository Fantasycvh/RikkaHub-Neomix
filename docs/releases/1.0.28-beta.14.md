### 🖼 界面：液态玻璃（本版主功能）

基于 haze 2.0.1 的液态玻璃工程化落地：

- **门控层**：模糊/玻璃效果统一走门控（可读性优先），玻璃层父子结构拓扑，规避闪退
- **BLUR / GLASS 二选一**：输入栏、顶栏、列表**三处各自独立**选择背景效果（模糊 / 液态玻璃 / 关闭）
- 可读性模式兜底；顶栏穿底模糊（悬浮层采样内容、垫底层绝不采样）
- 助手背景图归一化：`backgrounds/` 专用目录 + 屏幕比例裁剪降采样 + 存量迁移（上游 #2127 同款坑根治）

### 🧩 新功能

- **角色卡内嵌世界书**：角色卡的 `character_book` 拆分为独立世界书并按 id 绑定助手；导入重复检测（卡内容指纹 + 允许继续的确认弹窗）
- **划词翻译弹窗**：跨应用选中文本 → 系统PROCESS_TEXT 直达轻量翻译（借 Miffan 方案，自带模型选择器、chatModelId 兜底）
- **工作区镜像站两件套**：rootfs 下载测速 + 包管理器一键配置国内源（apt 站点走 http，装机默认 TUNA）

### 🛠 稳定性与修复

- **数据库降级不再丢档（自本版起生效）**：SCHEMA_VERSION 漂移根治（常量对账单测为编译期主闸 + 运行时哨兵走 CrashHandler 上报）；降级隔离重建——`DowngradeQuarantineStore` 把旧库整体隔离保存后新建库，启动时弹窗告知 + 恢复提示 + 备份页常驻入口。**适用边界**：从更高数据库版本的安装**回退到本版或更高版本**时受保护（隔离档在装回足够新的版本后可恢复）；回退到 beta.13 及更早的旧版自身无防护，仍为旧行为（第一跳无解，属原理限制）
- **停止后立即发送不再卡队列**：停止生成后紧跟的新消息滞留在已暂停的队列里不执行（同上游 `281c9525a`）
