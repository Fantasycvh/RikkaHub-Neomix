### ⏰ 定时 AI 任务（本版主功能）

助手现在可以定时自主干活：闹钟 + 前台服务后台触发，到点按任务的执行目标驱动 AI 运行。

- **执行目标三态**：在已有会话继续 / 使用专属新会话 / 每轮新建会话（NEW_EACH_RUN 支持自动清理旧会话、保留最近 N 条）；会话可附带长期目标（goal），创建/编辑入口在会话内与「+」面板
- **周期**：一次性 / 每日（支持一天多时段）/ 每周 / 每月
- **AI 管理任务**：AI 可在对话中创建/调整定时任务（应用侧双层开关：总开关 + 会话级授权）
- **收尾闸门**：任务产出按「可交付」混合判定收尾，避免空转多轮
- **隐形会话**：任务专属会话可在会话列表中隐藏（手动切换）
- **运行账本**：每次执行一行（含 SKIP 与失败原因），运行历史二级详情页
- 备份核验对定时任务表生效；删除任务加二次确认；创建表单改整页（修输入抖动/失焦）

### 🛠 稳定性与修复

- **第三方中转兼容**：部分中转返回空 / 非标准 `role` 导致解析崩溃、整轮流式生成中断——现宽松匹配并回退 assistant（上游 #2266）
- **SAF 导出防闪退**：部分 ROM 文件选择器返回的 Uri 未真正创建文件时 `openOutputStream` 抛异常未捕获——现移入 IO 协程并捕获（上游 #2263/#2264）
- **拖拽排序抽搐全仓治理**：拖到列表边缘自动滚动时顺序来回跳（助手列表 / 标签 / 提示词预设 / lorebook / 提供商 / 模型 / API keys / 搜索服务 / 媒体 / TTS / ASR 等 13 处列表统一改为「拖动改本地顺序、松手才落盘」，推广自上游 #2229 的修法）
- 旧存档 blob 的 `stepCount:null` 不再炸会话
- ask_user 工具「跳过提问」按钮不显示（回调链漏传）
- 崩溃完整堆栈本地留存（`logs/` 目录追加 crash 文件，保留 5 份）
