## RikkaHub Neomix — 1.0.28-beta.6 预发布 / pre-release (308)

**仅 tag，无预编译资产**（本仓不发预编译包，请按 README 自行构建）。
**Tag only — no prebuilt artifacts.** Build from source per the README.

非官方 fork，与上游 [rikkahub/rikkahub](https://github.com/rikkahub/rikkahub) **无从属关系**；AGPL-3.0。
Unofficial fork, **not affiliated** with upstream. Feedback via Discussions.

`versionCode` 从 **307 递增到 308**，便于区分两次预发布；数据库版本为 **47**。

### 三类记忆（画像 / 话题 / 事务）

- 记忆实体新增 `kind`（画像 / 话题 / 事务）与事务生命周期字段（`task_status`、`due_at`），迁移 **46 → 47**；旧锚点记忆回填为画像
- 整理器按记忆类型校准：画像沉淀稳定偏好，话题保留上下文，事务跟踪进行中/已完成
- 整理时可单独调整记忆类型（独立开关，默认保持原类型）
- 记忆页支持分类筛选、事务操作，以及恢复元数据展示
- 备份导入时，原版记忆文件按内容映射到画像 / 话题；上游对话与 checkpoint 语义继续兼容

### 对话与上下文

- 上下文占用指示器**只保留圆环**，移除长条形态与切换开关
- 手动压缩支持可选「保留最近 N 条」下限，避免压缩后最近上下文丢失
- TTS 朗读前剥离 HTML 标签，不再读出 `<details>` 等标签名
- Markdown 数学公式转义 `math span` 内的 `<`，避免公式被 Jsoup 截断
- 移除实验性悬浮小窗（双宿主、浮窗服务、设置项与设计稿一并删除）

### 提供商与设置

- **移除提供商分享**（分享面板 / 二维码导出）
- **移除二维码导入与「推荐提供商」列表**；提供商列表只保留「新增」，详情页不再有分享入口
- 同步移除扫码相关 CameraX / zxing 依赖、设置搜索索引与无引用字符串
- 保留相机权限仅用于快捷方式拍照，与提供商功能无关

### 备份、安全与稳定性

- 兼容上游 3.1.0 的对话/checkpoint 导入语义；本仓导入的 checkpoint 统一按压缩类型处理
- 本地导入/导出页签前置，和 WebDAV 等入口更好找
- Web 访问强制鉴权，修复凭据泄露与服务生命周期问题
- 请求日志脱敏；附件落盘与 base64 保存移出主线程；修正流式结束语义、重连与空回复处理
- 新增翻译历史（最多 100 条）

### 上游同步与体积

- 上游 `26454cc`：窗口主题改用系统 `Theme.Material`，R8 可裁 Material Components 资源
- 上游 `80845dd`：全文搜索去掉 jieba 词典与 14MB `simple_dict`；中文用单字 `NEAR`、英文/数字用 `simple_query`
- 占位图由 PNG 改为 WebP
- arm64 release APK 约 **60MB**（beta.5 约 71MB）；主要来自去掉 `simple_dict`、扫码/ML Kit 依赖与主题资源裁剪
