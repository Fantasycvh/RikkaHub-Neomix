## RikkaHub Neomix — 1.0.28-beta.24 (328)

### 更新内容

- 媒体生成链路统一：生图模型统一走 mediagen 执行入口与统一模型目录，按任务授权使用；模型级能力与凭据共享、多 key parity、模型级自定义 header/body；Gemini 与 OpenRouter 生图适配器收编进统一链路。
- 生图提交新增「待确认」状态与中断恢复语义；按请求 ID 对账，应用启动期自动找回提交窗口中断的生图任务。
- 压缩摘要对用户可见并允许编辑；消息概览中标注压缩点位置。
- 压缩完成报告轻量版：展示节省量估算；轮前自动压缩失败不再静默、可见可查。
- 输入超窗反应式兜底：压缩恢复后同一步自动重发，不再因上下文超限中断。
- 会话列表支持批量多选删除。
- 选图支持先裁剪后绘制：裁剪页新增画板动作，单张选图一律先进裁剪。
- 定时任务模板支持生成操作与素材引用。
- 隐私脱敏管线：压缩侧密钥脱敏，导出与 Web API 内容脱敏。
- Phone Use：执行期间通过 WakeLock 保持亮屏；护栏预算支持 0 表示不受限；微信移入内置黑名单。

### 问题修复

- 保留 DeepSeek 内置搜索回复的正文显示。
- 生图快照按 `output_format` 拼真实 MIME 类型；默认生图模型未显式选择时兜底解析。
- 删除会话附件前做引用计数保护——fork/分支复制、同一附件发到多个会话时不再误删共享文件。
- 升级 bettertext 至 v0.1.6：修复 LaTeX 多重积分（`\iint`/`\iiint`）与被积函数重叠、度数符号间距。
- Release 包保留 SnakeYAML 包名，修复技能 YAML 解析崩溃。

### Updates

- Media generation is unified: image models run through the mediagen pipeline with a unified model catalog and per-task authorization; model-level capabilities, shared credentials, multi-key parity, and per-model custom headers/bodies; Gemini and OpenRouter image adapters are folded in.
- Image generation gains a "pending confirmation" state with interruption recovery; submissions are reconciled by request ID and automatically recovered at startup.
- Compression summaries are visible and editable; message overview marks compression points.
- A lightweight compression report shows estimated savings; failed pre-turn auto-compression is no longer silent.
- Reactive fallback for overlong input: after compression recovery, the same step is resent automatically.
- Conversation lists support multi-select batch deletion.
- Image picking supports crop-then-draw: the crop page gains a canvas action, and single-image picks always go through cropping first.
- Scheduled task templates support generation actions and asset references.
- Privacy redaction pipeline: secrets are redacted in compression, exports, and the Web API.
- Phone Use: a WakeLock keeps the screen on while running; guardrail budget 0 means unlimited; WeChat moves to the built-in blocklist.

### Fixes

- DeepSeek built-in search replies keep their text.
- Image snapshots use the real MIME type from `output_format`; the default image model falls back correctly when none is explicitly selected.
- Conversation deletion now reference-counts attachments — shared files (forks, multi-conversation) are no longer deleted.
- bettertext upgraded to v0.1.6: fixed LaTeX multiple integrals (`\iint`/`\iiint`) overlapping the integrand and degree-sign spacing.
- SnakeYAML package names are kept in release builds, fixing skill YAML parsing crashes.

### 升级 / Upgrade

从 beta.23 覆盖升级会将数据库从 75 迁移到 78。升级前请在「设置 → 备份」保存副本。回到旧版本需要重装旧版并恢复升级前的备份。

Upgrading from beta.23 migrates the database from version 75 to 78. Back up in Settings before upgrading. To return to an older version, reinstall it and restore the pre-upgrade backup.
