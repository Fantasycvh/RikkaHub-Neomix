### ✨ 本次更新 / What's New

**思考强度映射支持自定义**（模型级覆盖 + 提供商级兜底）

- 各家 API 的思考参数方言（`reasoning_effort` / `thinkingLevel` / `thinking_budget` 等）此前硬编码，中转站/私部署对不上时无法调整
- 模型级：提供商详情 → 编辑模型 → 高级设置 → 「思考强度覆盖」，可自定义 Effort 文本与 Budget 数值
- 提供商级：提供商配置页底部「思考强度映射兜底」，对该提供商下所有未单独覆盖的模型生效
- 解析链：模型级 → 提供商级 → 内置映射；仅在选择具体思考档位（关闭/自动之外）时生效，旧配置零迁移

**记忆整理推理强度可配**（移植上游 72d419171 增量）

- 设置 → 模型 → 「做梦（记忆整理）模型」下新增「整理推理强度」（已配置该模型时显示）
- 对整理实际用上的模型生效（做梦模型或回落链上的快速/对话模型）；「自动」= 原行为

**动态取色增强**（Android 12+）

- 支持自定义种子色：偏好设置 → 主题 → 「种子色」，不再只能跟随壁纸；选「跟随壁纸」恢复原行为
- 动态取色时中性灰阶（gray1–10）跟随取色色调插值生成，与主配色更协调；语义色（红/橙/绿/蓝）保持固定

**消息编辑修复与增强**

- 修复「回复1 → 工具调用 → 回复2」形状的消息只能编辑最后一段的问题：多文本段消息支持按段编辑，编辑不再丢失工具调用记录

**其他改进**

- 自动压缩触发阈值改为滑杆 + 直接填写（原为固定 60/70/80/90 四档）
- 获取模型失败的错误卡片新增「复制错误信息」按钮，便于反馈排查
- 世界书/注入导入器兼容外部工具的枚举大写常量名（原报「格式不支持」的文件现可直接导入）

**修复**

- 修复提供商详情页模型列表长按无反应、无法拖动排序的问题（排序管线一直存在但没接触发器）
- 修复收藏模型拖动排序时来回抽搐的问题（移植上游 395a0ee0）
