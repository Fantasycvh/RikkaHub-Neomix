约定：

- 资产只发 **arm64-v8a**，文件名 `Neomix-<versionName>-arm64-v8a.apk`；签名密钥为自签 `CN=neomix`，
  证书 SHA-256 `D1:5B:69:3A:20:10:B2:EE:5F:78:F3:A6:EE:D0:A1:57:E0:74:B4:B2:0F:47:6E:C3:1F:5C:91:74:D9:4E:EC:78`
  （与 `beta.1` 起同一把；CI 发版流水线有固定指纹验签闸）⇒ 可覆盖升级；**换密钥需卸载重装**。
- 每次发布后在说明里给出 **SHA-256**，并用 GitHub API 回读资产 `digest` 与本地产物比对。
- 本表按 `docs/handoff-2026-09-04.md` 的发版流程登记；`beta.8`…`beta.14` 为 2026-10-31 补登。
