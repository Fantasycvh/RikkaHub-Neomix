### ✨ 任务通知与收件箱（首期，rollout 默认关）

- **shell 后台命令终态投递**：命令结束（含秒退/启动失败）把终态与输出快照写入收件箱，投递到发起会话；命中选中分支才接收，消息写入与确认同事务
- **任务完成后主动唤醒会话**：空闲时自动开一轮向模型汇报，用户消息优先携带；审批等待/用户暂停/窗口不足时不自动续跑；每根 scope 一次
- **步骤间 Notice**：生成中的会话在步骤之间注入通知，前缀稳定可命中提示词缓存；通知可删除，导出/记忆整理/压缩自动跳过
- **可靠记忆同步与运行摘要**；保留后台任务并立即处理新消息
- 入口：设置 → 通用 →「后台命令完成后自动处理」（默认关，验收期保持旧行为）
- 配套：定时任务**每日随机时间窗**（固定种子算法、跨日不追帧、DST 安全）；scheduled 注入轮的 `memory_tool` 审批桥（三批上限 + 五分钟预算）

### ✨ 界面

- **顶栏样式两套共存**：整条穿底模糊（原样）与**浮动胶囊**（上游同款，按钮各自成胶囊、随滚动淡入）设置页二选一

- 任务中心聚合后台命令通知卡片（Android / Web 双端）
