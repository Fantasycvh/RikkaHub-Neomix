### ✨ 外观皮肤体系（实验性）

- **统一皮肤契约**：原生按钮/输入框、聊天框架/抽屉、复杂卡片等宿主持久接入皮肤默认样式，覆盖审计按页回归
- **有界皮肤包与原子安装**：本地皮肤包管理与资源编辑、版本保留、校验失败回滚、一步撤销、跨页试用
- **嵌入式皮肤**：自有 HTML 与终端画布主题化；气泡材质（渐变/图案/噪点）、玻璃气泡与渐变文字、可插拔消息布局与共享外观控制
- **中央动效令牌** MotionTokens 收口动效参数
- 皮肤仅从本地包加载并带资源边界与校验闸；仍属实验特性，建议保留默认主题兜底

### 🤖 Phone Use：AI 操作手机（实验性，新功能）

- 通过无障碍服务读屏并操作本机其他应用：元素树为主、截图按需，支持点击/长按/滑动/滚动/输入/打开应用/等待
- 仅 App 交互回合可用；定时任务、子代理、Web/API 远程会话不装配该工具
- 每轮首个变更动作需确认「允许本轮」，审批默认开；批准后本轮不再重复询问，拒绝后本轮不再执行
- 隐私：支付/银行内置黑名单 + 用户可编辑追加包名（本地工具页「被禁应用」），持续检查所有可见窗口；只读应用窗口；密码节点文本不入上下文；截图独立目录且不进备份
- 60s 审批超时按拒绝处理，避免挂住生成；截图/手势期间悬浮窗让位并在审批时自动展开
- **已知限制**：微信疑似已下发防截图/防读屏配置，Phone Use 对其截图与元素读取可能失败；
  后续可能要求具备相应模块/配置才能操作该应用
- 入口：助手详情 → 本地工具 → Phone Use（需 Android 11+ 并在系统设置中开启无障碍服务）
