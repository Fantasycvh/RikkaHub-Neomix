# RikkaHub Neomix — 1.0.28-beta.26 (330)

### 更新内容

- 手动压缩后台化（上游 7f11a5f15）：确认后弹窗即关，任务迁入常驻服务（切走页面/切换会话不中断）；聊天页输入框上方提示条展示三档阶段文案并支持取消；压缩期间可继续聊天，不排队不禁发送；「在新会话继续」fork 完成后自动跳转或 toast 提示。
- 压缩多步二期：token 预算分块、滚动摘要与锚点精炼遍；压缩分界线可撤回，补齐删线即还原闭环（NMoi D324–D327）。
- 工具输出预算二/三期：两级限幅预留结清与单一分级压缩器；确定输入超窗时撤回最大工具结果同轮重发，与反应式压缩互补（NMoi 11-17）。
- 斜杠命令系统：分组补全弹窗、11 个高频命令、发送时盲打解析与多 Skill 叠加底座；定时任务支持提示词 `/skill` 补全与触发双路径自动注入。
- 局域网双向同步：会话与附件双向对称同步（Cuplivo 模式），mDNS 自动发现与断网恢复；接入加密本地快照备份。
- 媒体生成支持会话内连续创作与可恢复任务。
- 独立对话归纳支持复用 Prompt Cache，并与定期整理（做梦）拆分模型配置（上游 #2386）。
- 流式滚动三态：跟随底部 / 锚定回复开头 / 不滚动（上游 #2371）；新增 ChatGPT/Gemini 式「锚定开头」——回复首行停在视口顶部后不再跟随。
- 发送前敏感凭据检测与多语言提示。
- 聊天顶栏三段式液态胶囊光学质感与渐变高光棱边；统一状态栏折叠与待审批定位，输入栏高度升级与建议长按发送。
- 记忆工具审批支持修改前后内容对比预览。
- 设置首页补充 trailingValue 状态摘要；设置搜索跳转自动展开 advancedGroup 并滚动高亮定位。
- Phone Use 虚拟屏加固；支持安全模式导入备份。
- 可见性动效门控与后台缓存回收（长列表性能）。
- 上游小改同步：录音时保持屏幕常亮（cc8735431）；媒体生成轮询间隔 15s→5s（e258d9de2）；连接测试按模型级覆写配置（1fb091529）；新聊天入口移出溢出菜单（4be258f5f9）。

### 问题修复

- 发送图片 OOM（上游 f37f66b31 / #2365）：像素上限降至 4MP + 两段式精确缩放解码；组装请求 OOM 时暂停消息队列并给出可读错误提示，不再空转连环失败。
- IME 输入陷阱批次清理：设置类静态表单页迁离 LazyColumn（常驻 Column + imePadding）；消除全仓格式化直绑与写穿回灌；多字段对话框键盘适配补齐；A' 豁免清零。
- TikZ 原生库对齐 16 KB page size。

### Updates

- Manual compression runs in the background (upstream 7f11a5f15): dialog closes on confirm, the task moves into the resident service (survives page/ conversation switches); a bar above the input shows the three-stage progress and can cancel; chatting continues during compression; "continue in new conversation" fork auto-navigates or toasts.
- Compression multi-step phase 2: token-budget chunking, rolling summary and anchor-refinement pass; compression divider is undoable (NMoi D324–D327).
- Tool output budget phase 2/3: two-level clamping with reserved-settlement and a single tiered compressor; on overflow, the largest tool result is retracted and the turn retried (NMoi 11-17).
- Slash command system: grouped completion popup, 11 frequent commands, send-time blind-typing parsing and multi-skill stacking base; scheduled tasks support prompt `/skill` completion and dual-path auto injection.
- LAN two-way sync: conversations and attachments sync bidirectionally (Cuplivo model) with mDNS discovery and offline recovery; encrypted local snapshot backup.
- Media generation supports in-conversation continuous creation and resumable tasks.
- Standalone conversation digest can reuse Prompt Cache and has its own model config, split from dreaming (upstream #2386).
- Three scroll modes: follow bottom / anchor at start / none (upstream #2371); new ChatGPT/Gemini-style anchor-at-start — the first line of the reply stays at the viewport top and scrolling stops following.
- Sensitive credential detection before send with localized prompts.
- Three-segment liquid-capsule top bar optics; unified status-bar collapse and pending-approval positioning, upgraded input bar height and long-press-to-send suggestions.
- Memory tool approval shows a before/after content diff preview.
- Settings home shows trailing value summaries; settings search jumps expand advancedGroup and scroll-highlight the target.
- Phone Use virtual display hardening; safe-mode backup import.
- Visibility-based animation gating and background cache eviction (long-list performance).
- Upstream small syncs: keep screen on while recording (cc8735431); media polling 15s→5s (e258d9de2); connection test honors per-model overrides (1fb091529); new-chat moved out of overflow menu (4be258f5f9).

### Fixes

- Image OOM on send (upstream f37f66b31 / #2365): pixel cap lowered to 4MP with two-pass precise scaling; OOM while assembling a request now pauses the queue with a readable error instead of failing in a loop.
- IME input trap batch cleanup: static settings form pages moved off LazyColumn (resident Column + imePadding); eliminated format-bound text fields and write-through feedback across the repo; multi-field dialogs keyboard adaptation; A' exemptions cleared.
- TikZ native libraries aligned for 16 KB page size.

### 升级 / Upgrade

从 beta.25 覆盖升级会将数据库从 80 迁移到 82。升级前请在「设置 → 备份」保存副本。回到旧版本需要重装旧版并恢复升级前的备份。

Upgrading from beta.25 migrates the database from version 80 to 82. Back up in Settings before upgrading. To return to an older version, reinstall it and restore the pre-upgrade backup.
